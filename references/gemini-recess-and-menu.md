# Gemini 凹槽与下拉浮层

用户明确指出：初版输入槽与 Gemini UI 相比缺少质感，且没有复现 Gemini 的下拉选项。这两项应作为该技能的重点结构，而不是可省略的装饰。

2026-10-13 直接读取了用户提供的 `http://127.0.0.1:8077/Gemini%20UI/css/styles.css`，响应为 200；其关键结构与本技能保存的 Gemini 原始源码一致。原地址仅供当时核对，技能不依赖该服务。

## 凹槽为什么不能只用一个 inset 阴影

Gemini 的 `.chat` 外框是深灰蓝到白色的线性渐变，padding 为 4px、外圆角 40px；`.chat-inside` 是独立层，圆角 35px、底色 `#E1E9F1`。内层原始配方：

```css
box-shadow:
  inset 0 0 12px #022143,
  inset 0 -7px 4px rgba(255,255,255,.6),
  inset 0 4px 3px rgba(154,169,184,.6);
```

外框表达边缘截面，周边深影表达内槽，下方白光表达反射，上侧短暗影表达光源方向。省掉外框、减少圆角差或大幅降低深影强度，会变成普通柔和输入框。

实现为 `assets/recessed-controls.css` 与 `assets/recessed-controls.js`：

- 搜索框：外层 4px 渐变框和独立 search-inner；输入自身透明、无额外 outline。
- 表单：recess-frame 包住 field 或 textarea；小控件缩放阴影半径但保留倒角与反光。
- 对话输入：composer-inner 保留 40/35px 双层圆角和完整原始三层阴影。
- 错误字段调整槽边缘的语义色，并保留错误文字。
- 聚焦时轻微加强内槽，不新增一个悬浮方框；不要关闭所有按钮的键盘焦点。

五套主题分别调整材质色和深影色；牛油果绿使用深绿槽影，不把整个层次改成低对比浅绿。

## 透明下拉菜单的原始配方

```css
background: rgba(255,255,255,.1);
backdrop-filter: blur(2px);
border-radius: 15px;
box-shadow:
  0 4px 8px rgba(152,169,186,.8),
  inset 0 2px 2px rgba(123,142,161,.8),
  inset 0 -2px 2px rgba(249,253,255,.9);
```

菜单项悬停为低透明度灰色，菜单本身透出经过轻模糊的背景。不要用原生系统选项窗或全实色卡片声称复现了这个效果。工具菜单、选项浮层和上下文菜单应沿用相同边缘与光照；深色主题提高遮罩底色以保持文字可读。

当前实现保留原 select 的表单值，用触发按钮与 listbox 绘制菜单；支持点击选项、点击外部、Esc、方向键、Home/End 与焦点返回。接近视口底部时自动向上展开，设置页菜单靠右对齐避免窄屏越界。

## 覆盖全部组件族

用户要求将此材质统一应用到其他组件。样式加载顺序为 studio.css → materials.css → recessed-controls.css → component-materials.css。不要只复制输入框的样式而漏掉 shared skin。

component-materials.css 覆盖按钮、图标与按钮面、分段槽、页签、面包屑、列表、表格、属性表、树形容器、卡片、图表、轨道、仪表读数、标签、状态条、骨架、对话与弹层。凸起按钮沿用开关圆帽的外倒角、内层 btn-face、接触影和远投影；异步或运行状态改变时重新保留内层结构。

上传区由 dropzone 渐变套框、dropzone-well 深凹槽和独立选择按钮组成；文件输入保留本地选取行为，文件名、拖入与移除反馈在槽内显示。横向 range 和纵向均衡器复用 toggle-knob / toggle-knob-face 圆帽；原生 input 为透明交互层，视觉圆帽位于轨道上方。

分段选择的按钮等宽，segment-face 保持一个完整选中凸面。选择型控件未选中态保持旧版的凹面或透明样式，只在选中态使用新的圆帽凸面，避免整体样式变动过多。底部导航保留图标与标签的轻巧比例，navigation-tray 位于实体底座内，仅选中项加独立凸面；不要将三个入口都变成大号金属按键。分页当前项以主题边缘、数字字重与短标记强化，不依赖难辨的灰度变化。

进度条的槽体沿用拨杆开关：外框与内轨分开，进度色作为槽内的光色嵌条，轨道的投影合成层位于色条上方。0% 时色条和辉光消失，100% 仍保留两端槽缘，颜色不覆盖整个槽体的倒角。

卡片和外壳使用凸面与投影，输入、轨道、数据窗口和选择槽使用凹面；不是将所有组件设置成同一道阴影。语义红绿灯与精密金属原始光影不被共享材质覆盖。

## LVGL 对应策略

凹槽使用外层渐变套框与内层对象分开，精细内阴影可预渲染背景；不能假定 LVGL 原生支持 CSS inset。下拉用 `lv_dropdown` 的主控件与列表部件分别设置颜色、边缘、透明度和状态。网页 backdrop blur 没有直接等价的通用低成本原生属性；根据硬件选择半透明背景或预渲染场景，不虚构该 API。
