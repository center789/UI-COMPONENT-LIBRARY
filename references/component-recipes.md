## 后续可以继续扩展的方向

- 录音：石墨圆形录制键、红色小灯、清晰时长；红色属于该功能的语义扩展。
- 均衡器：银雾底板、并排细长凹轨、小型金属滑块。
- 亮度或曝光：旋钮配数值和单位，灯点可以映射离散档位。
- 参数卡片：标题与标签保持平面，数值区域内凹，操作键略凸。
- 仪表导航：冷灰蓝分段槽，选中标签成为凸面，其他标签保持清楚。
- 状态通知：薄内凹条、灯点与文字，不做大面积发光。
- 模型或设备选择：类似 Gemini 的轻浮层，边缘清楚，键盘可关闭。
- 保留型主操作：重要动作放在更厚的实体面上，但遵守原业务确认流程。

## 实现细节

- CSS 变量拆分背景、操作面、槽影、亮边、文字、强调色、状态灯；不要每个组件写一套无关联的颜色。
- 静态结构用 HTML/CSS/SVG；没有空间相机或真实 3D 场景需求时不必引入 WebGL。
- 装饰伪元素设 `pointer-events: none`；交互元素保持命中区域、焦点和文字可读。
- 启动演示采用可切换 checkbox，真实产品根据业务运行状态渲染；不要照搬隐藏输入与无限动画作为后端逻辑。
- 不复制原例的全局 `transition: all` 或 `user-select: none`。限制过渡属性，让输入、文本和读数可以正常选择。
- 旋钮的底板、金属光影、刻度保持固定，仅指针或有明确机械意义的内层旋转。
- 环形灯点用角度映射，数值 0% 时全灭，100% 时全亮，中间按统一取整规则。
- 自定义连续拖动加入上下限、Pointer Capture、取消处理；原生 range 可以作为可靠的基本操作入口。
- hover 效果同步给 focus-visible；移动设备应有点击或按压反馈，不依赖大型透明 hover 覆盖层。
- 动画只改变小范围元素；减少动态模式下停用扫光与呼吸，保留文字状态。

## 有意义的验证

依实际组件核验：分段选中唯一、开关读数同步、旋钮的最小与最大值映射正确、键盘改变范围、启动时扫光且停止后结束、方向按钮有明确输出、窄屏不横向溢出。视觉验证应看真实渲染，不以 CSS 是否存在某个属性代替。
