# 网页组件完整清单

当前工作台包含 64 个组件组、5 套材质、3 个网页组合页。每组可有多个状态或变体，数量指组件组，不把每一种颜色计算为新的组件。

网页预览：`assets/index.html`。共享 CSS：`assets/studio.css`；原始金属光影：`assets/materials.css`；图标：`assets/icons.js`；组件结构与映射：`assets/component-catalog.js`；交互：`assets/studio.js`。原始光影对照在 `assets/shadow-study.html`。

## 必须验证的细节

- 小屏还要检查工具栏内按钮之间是否重叠；创作页工具栏在窄屏分为参考/工具、模式/发送两组。手机分类菜单与桌面下拉复用同一透明浮层，动态更新 options 后刷新可见列表。
- 输入框聚焦时不会出现额外方形框；凹槽自身承担轻微焦点反馈，键盘按钮仍有清晰焦点。
- 小按钮、方向键、加减、键盘文字居中；使用 SVG 与稳定行高，检查字体 fallback。
- 开关红/绿灯与滑块位置、开/关文字同步；连接与运行同语义，禁用为中性灰。
- 下拉/浮层可点击外部或按 Esc 关闭，模态焦点不跑到背景，关闭后返回触发控件。
- 范围滑杆上下限不交叉；步进器到达边界禁用对应按钮；旋钮角度、灯点和读数一致。
- 异步演示可重置，无悬挂计时器；输入的文本按文本显示，避免作为 HTML 注入。
- 五套材质、桌面/平板/手机均检查实际渲染与溢出，不把 CSS 属性存在当成验证。
- 按分类查看完整组件区截屏，不能只截首屏；弹层还要实际打开。上传区拖入与移除、分页当前项、分段等宽和底部导航选中都需要单独检查。
- 圆帽与轨道共享状态但分开绘制：圆帽在轨道上方，进度色则在凹槽内、槽缘投影下方。检查合成层级，避免参数相同但视觉被轨道横穿。

## 材质覆盖的核对方法

| 分类 | 应检查的结构 |
| --- | --- |
| 动作与按钮 | 主、次、图标、矩阵和异步按钮保留内层面，按下不丢层 |
| 表单与选择 | 输入、下拉、复选、单选、圆帽、上传分别有合适的槽与反馈 |
| 导航与流程 | 等宽分段、清楚分页、步骤圆片、菜单和轻巧底部导航 |
| 数据与读数 | 读数凸卡、表格与树形凹窗、仪表暗环、进度槽内色 |
| 反馈与状态 | 提示槽、徽标、红绿灯、骨架、加载、空状态和通知 |
| 弹层与展开 | 展开菜单的玻璃边缘、对话框和侧栏的层级与焦点 |
| 卡片与布局 | 卡片倒角、头像接触影、气泡槽边、设备图形与分栏 |
| 设备与控制 | 保留原旋钮，均衡器圆帽、滚轮选中面、键盘和连接条 |

## 使用范围

当前清单覆盖常见网页类型，并非宣称列尽所有产品特有控件。出现新的业务控件时沿同一规则扩展，保留现有状态语义。网页原型行为都是本地演示，不宣称上传、付款、聊天服务或设备通信已经接入。
