# 保留原始材质深度

用户明确指出：原样式库过于柔和，阴影与真实拟态旋钮的质感差距大。后续默认参考原始源码的层次，不将关键机械控件简化成两道浅色模糊阴影。

完整实现放在 `assets/materials.css`，该文件在基础 `studio.css` 之后加载。`assets/shadow-study.html` 提供原始截图与还原截图对照，`component-catalog.js` 中的第 59 项提供真实方向操作。

## 精密机械台的原始配方

四个直径：外圈 200px、内腔 155px、金属帽 102px、帽面 85px。外圈的亮暗渐变与帽面的渐变相反，以表达凹与凸。不要只换颜色而保留同一渐变方向。

内腔叠加 5 层阴影，其中三个 inset 的范围为 16/24/48px，黑色透明度分别为 .85/.75/.2。内腔很深是该参考的关键特点，不应擅自削弱到一层灰蓝槽影。

金属帽叠加 6 层：

```css
box-shadow:
  0 9px 14px rgba(0,0,0,.5),
  0 19px 8px -2px rgba(0,0,0,.2),
  0 33px 8px rgba(0,0,0,.4),
  0 -12px 10px rgba(255,255,255,.5),
  inset 0 3px 3px rgba(255,255,255,.6),
  inset 0 -3px 3px rgba(89,91,92,.6);
```

三层不同距离的黑色投影表达操作面离开槽底的高度；上方宽白光是环境反光；两道窄 inset 是金属倒角。四个小定位点也有外投影和 inset，不能用没有光影的平面圆点代替。

方向操作约 5px 位移、8° 倾斜，投影的偏移、长度和反光位置随方向变化。外圈与环境光不旋转。将方向操作改为真实按钮，保留键盘焦点，避免原演示中大型透明 hover 区域遮挡相邻控件。

## 音量台与小控件

音量台按 262/245/190/148 的比例形成套环、底床和操作帽。使用左侧高光与右侧三段投影；帽子右侧的长影包含 `22px 0 28px rgba(2,29,37,.6)`。缩小时按尺寸缩放偏移和模糊半径，不把阴影透明度一并大幅降低。

凸起按钮统一采用拨杆开关圆帽的双层配方：外倒角与内帽面分开，方形、胶囊和小型按键适配相同材质，按实际尺寸缩放接触影、远投影和窄反光；输入框按 Gemini 的上暗下亮凹槽结构设置。正文和数据容器可减弱投影，但关键旋钮、控制键和输入槽必须保持明确凹凸，不把减弱长文背景的规则错误应用到主控件。

牛油果绿是同一套材质的配色扩展：保留原始阴影层次与强度，控件颜色从共享主题变量取值。用户明确要求圆形图标按钮与其他控件配色一致，外圈、内腔、金属帽、图标面、仪表和滑块不能另用固定银灰皮肤；语义红绿灯保持固定状态含义。

## 验证与 LVGL

在实际像素尺寸查看原源码与还原控件，注意组件截屏可能因坐标的小数产生一像素的边缘差异。检查静态、按下与各方向状态，避免用布局盒居中检查替代材质质量检查。

LVGL 原生低成本样式不等同于这套 CSS 多层投影；要求完全保留原始光影时优先预渲染相应层或状态资源，再用原生按钮、焦点、数值与事件组合。按硬件预算验证，不承诺通用软件阴影参数达到同样画质。
